# NZ Property Tracker

Track rental properties and renovation projects: costs, reno budget, yields, and mortgage re-fix dates.

## Run it

Open `index.html` in any web browser. There's nothing to install.

Your properties are saved in that browser on that device. Clearing your browser data will remove them.
